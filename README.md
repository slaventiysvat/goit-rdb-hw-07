# GoIT RDB HW-07 — Робота з часом та JSON (Northwind)

## Передумови

- MySQL Server 8.0+
- MySQL Workbench (або будь-який MySQL клієнт)
- База даних **northwind** — створюється зі скриптів у [hw-02](../hw-02/HW2/)

## Підготовка бази northwind

Якщо база ще не створена — спочатку виконайте скрипти з hw-02:

1. Відкрийте та виконайте `../hw-02/HW2/hw2.sql` — створює схему (таблиці).
2. Відкрийте та виконайте `../hw-02/HW2/hw2_data.sql` — заповнює таблиці даними.

## Як запустити

1. Відкрийте MySQL Workbench і підключіться до свого сервера.
2. Переконайтесь, що база `northwind` існує:
   ```sql
   SHOW DATABASES;
   ```
3. Відкрийте файл `hw7.sql`.
4. Виконайте весь скрипт через **Ctrl + Shift + Enter** або окремі завдання — виділіть потрібний блок і натисніть **Ctrl + Shift + Enter**.

## Завдання

| # | Опис |
|---|------|
| 1 | Витягти рік, місяць і день з поля `date` таблиці `orders` |
| 2 | Додати один день до поля `date` |
| 3 | Відобразити UNIX timestamp для поля `date` |
| 4 | Порахувати кількість замовлень між двома датами |
| 5 | Сформувати JSON-об'єкт `{"id": ..., "date": ...}` для кожного рядка |
